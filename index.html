Connect Ollama

Ollama lets you run compatible open-weight models on your own computer.

Local does not mean automatic.

You must install and start Ollama, download a model, and allow your browser to connect to its API. No cloud AI provider is used by this project.

Use a model you have already pulled with Ollama. Model names and hardware requirements vary.

Demo mode is ready. Configure Ollama when you want local model inference.

How to enable local AI

  1. Install Ollama from ollama.com.
  2. Open a terminal and run ollama pull qwen2.5:3b.
  3. Start Ollama and confirm its API is reachable at the configured address.
  4. If the browser blocks the request, configure Ollama's allowed origins for your app's origin, then restart Ollama. Do not expose the API publicly.
  5. Test the connection above and generate content.
